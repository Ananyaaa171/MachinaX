# MACHINA-X Sensor Simulation Service

Physics-based telemetry simulation engine for a 3-Phase Induction Motor. Generates continuous, realistic, time-varying sensor streams and supports dynamic fault injection (`HEALTHY`, `BROKEN_ROTOR_BAR`, `STATOR_SHORT`, `BEARING_DEFECT`, `ECCENTRICITY`).

> **DATA SOURCE**: All telemetry generated by this service is clearly labeled with `source="SIMULATED"`.

---

## 1. Simulated Telemetry Channels (3-Phase Induction Motor)

| Sensor Type | Physical Quantity | Nominal Healthy Range | Unit | Dynamics & Modeling |
|---|---|---|---|---|
| **`VIBRATION`** | Overall RMS velocity | 1.5 – 2.5 | `mm/s` | Base target + fault harmonic bursts + Gaussian noise |
| **`CURRENT`** | Stator Phase RMS | 10.0 – 15.0 | `A` | Base target + slip/sideband modulation + Gaussian noise |
| **`TEMPERATURE`** | Stator / Bearing Thermal | 50.0 – 65.0 | `°C` | 1st-order thermal inertia ODE with realistic thermal drift |
| **`RPM`** | Rotor Speed | 2850.0 – 2950.0 | `rpm` | 4-pole synchronous baseline with slip fluctuation |

---

## 2. Configurable Fault Modes

1. **`HEALTHY`**: Standard baseline within normal IEEE / ISO tolerance envelopes.
2. **`BROKEN_ROTOR_BAR`**: +15–30% vibration RMS, ±2sf MCSA sideband current modulation, +5–10°C gradual thermal rise.
3. **`STATOR_SHORT`**: +5% vibration, +30% current asymmetry/distortion, rapid +15–25°C thermal escalation.
4. **`BEARING_DEFECT`**: +40–80% vibration RMS with BPFO impact bursts, slight current rise, +10–20°C temperature.
5. **`ECCENTRICITY`**: +10–20% vibration with 1x/2x rotational frequency modulation, current fluctuations.

---

## 3. REST Control Interface

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Service health status and `SIMULATED` data source tag |
| `GET` | `/api/v1/simulator/status` | Complete engine status, current/target mode, stats, and last batch |
| `POST` | `/api/v1/simulator/mode` | Switch fault mode: `{"mode": "BEARING_DEFECT"}` |
| `POST` | `/api/v1/simulator/step` | Manually advance one simulation step and return generated batch |
| `POST` | `/api/v1/simulator/start` | Start / resume automatic background transmission loop |
| `POST` | `/api/v1/simulator/stop` | Pause automatic background transmission loop |

## 4. Configuration (`.env`)

```env
MACHINE_ID=1
SIMULATION_INTERVAL_SECONDS=2.0
DEFAULT_MODE=HEALTHY
TRANSMIT_TO_BACKEND=true
LOG_LEVEL=INFO
```
